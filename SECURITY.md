# Security Policy

## Supported Versions
The latest stable version on the default branch is supported. Please upgrade before reporting a security issue if possible.

## Reporting Security Issues
Please do not disclose severe vulnerabilities publicly in GitHub issues. Report them privately.

Email: hello@aryanshinde.in

Include:
- Reproduction steps
- Technical details
- Proof of issue if available

Responsible disclosure is appreciated.

## Security Response
Reports will be reviewed and a reasonable effort will be made to investigate. Fixes are prioritized based on severity.
