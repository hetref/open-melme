## 1. Overview

A **Mailbox** is an isolated inbox container. Unlike the main Admin Dashboard, which has complete control, a Mailbox only has permissions to view, compose, and manage emails within its specific boundaries.

---

## 2. Why This Matters

Isolating mailbox security ensures that employees, freelancers, or individual departments can handle customer-facing emails safely without ever risking your main billing details, domain records, or other sensitive mailboxes.

---

## 3. How to Use It (Securing Mailboxes)

### 1. Unique Credentials
Each mailbox uses its own unique slug and password. When setting up a team, create one unique mailbox for each individual so passwords are never shared.

### 2. Session Revocation
If an employee leaves your company or a device is lost, you can terminate all their active mailbox sessions instantly:
1. Log in to the Admin Dashboard and go to **Mailboxes**.
2. Click **Edit** on the target mailbox.
3. Change the password and click **Save**. This will automatically log out all active sessions on any device globally.

### 3. Suspension Control
You can instantly disable a mailbox by toggling its **Active** switch off, locking out all access while keeping all historical messages perfectly safe.

---

## 4. Common Mistakes

* **Sharing passwords via text messages:** Do not send mailbox slugs and passwords in insecure chat apps. Use secure notes or a company password manager.
* **Failing to change credentials when team members leave:** Make password updates part of your employee offboarding checklist.

---

## 5. Tips

<Callout type="warning">
  **Important Safety Alert:** Because mailboxes do not have access to Admin Settings, mailbox users cannot see DKIM keys, buy domains, or view emails belonging to other mailboxes. Keep your workspaces separated!
</Callout>
